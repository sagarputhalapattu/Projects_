# 📊 Power BI Dashboard - Sales Analysis

This repository contains an interactive Power BI dashboard for **Sales Analysis**, designed to provide clear insights into overall sales performance, profitability, and top-performing products.

![Power BI Logo](https://img.icons8.com/color/96/000000/power-bi.png)

## 📁 File Details

- **File Name**: `Sale.pbix`
- **Created With**: Microsoft Power BI Desktop
- **Last Updated**: [Update with Date]

---

## 📌 Project Objective

The goal of this Power BI dashboard is to:
- Analyze total sales and profit trends
- Identify top-selling and underperforming products
- Provide a high-level overview of sales performance for better business decisions
- Present insights through dynamic and interactive visualizations

---

## 📂 Dataset Information

- **Source**: Excel File
- **Data Type**: Sales Transactional Data
- **Key Columns**: Date, Product, Category, Sales, Profit, Quantity, Region, Customer Segment

---

## 📈 Dashboard Features

The Power BI dashboard includes the following visual components:

- 📌 **KPI Cards** showing:
  - Total Sales
  - Total Profit
  - Total Quantity Sold
- 📊 **Bar & Column Charts** for:
  - Top 10 Products by Sales
  - Profit by Product Category
- 📈 **Line Charts** for:
  - Sales Trends Over Time
  - Monthly Profit Growth
- 🗺️ **Map Visuals** for:
  - Regional Sales Distribution
- 🧭 **Pie & Donut Charts** for:
  - Sales by Customer Segment
  - Profit by Region
- 🧮 **Slicers & Filters** to drill down by Product, Region, and Date

---

## 💡 Key Insights

- 💰 **Top Performing Products** contribute significantly to total revenue.
- 🧾 **Certain regions** show higher profitability with consistent growth.
- 📉 **Some product categories** may need attention due to lower profit margins.
- 📊 **Monthly trends** highlight peak sales periods and help forecast demand.

---

## 🛠️ How to Use

1. Clone or download the repository.
2. Open `Sale.pbix` using **Power BI Desktop**.
3. Refresh the data if needed (Excel source required).
4. Explore the report using the interactive visuals and filters.
